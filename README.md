# Survey Project

- [ ] Counter for each city through a page


# Quick Start

Install npm if you don't have it
```bash
brew install npm
```

Install dependencies
```bash
npm install
```

Run the app
```bash
npm start
```

and setup a AWS S3 bucket to store the data, and run the server:
```bash
# For the config, see `src/server/main.js`
export AWS_ACCESS_KEY_ID=<your_access_key_id>
export AWS_SECRET_ACCESS_KEY=<your_secret_access_key>
export AWS_REGION=<your_region>
export AWS_BUCKET_NAME=<your_bucket_name>

cd src/server
node main.js
```

Then go to [http://localhost:3000](http://localhost:3000) and fill out the survey.
